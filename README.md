# Varendra University CSE Class Routine
https://reemuree.github.io/VU_CSE_CLASS_ROUTINE/

An intuitive, easy-to-use web application for viewing the Computer Science & Engineering (CSE) department class routine at Varendra University.

🚀 Features
Quick Search & Filter: Quickly find routines by batch, section, or semester.

Responsive Design: Optimized for seamless viewing on both mobile and desktop devices.

Fast & Lightweight: Built for speed with minimal loading times.

## Live class and break countdown

The day view now updates every second. While a class is running, its card shows the remaining time as `MM:SS left` (or `HH:MM:SS left` for longer periods). During generated break/free periods, the break row shows the same live countdown. When the timer reaches zero, the class/break status automatically transitions without a page refresh. The timer uses the routine timezone (`Asia/Dhaka` for the current data).
